# Drama Education Project

本專案以三位故事結構專家為基礎，協助戲劇教育者與創作者設計、分析與改進劇本。

## 採用方法論

- **Nancy Duarte — Sparkline (Resonate)**
  - 交替現實與理想，強化故事張力。
- **Pixar/Kenn Adams — Story Spine**
  - "Once upon a time... Every day... Until one day..."，建立故事骨架。
- **Joseph Campbell — Hero's Journey**
  - 英雄旅程，普世故事結構。

## 使用方式

1. 參考上述方法論設計劇本結構。
2. 在創作、教學或分析時，明確標註所用框架。
3. 可結合三者優點，提升故事深度與吸引力。
