# Skill From Masters

> **站在巨人的肩膀上** —— 创建基于领域专家成熟方法论的人工智能技能。

一个帮助你在生成新技能之前发现并融入来自公认大师们的框架、原则和最佳实践的技能。适用于 Claude Code、Codex 及其他 AI 智能体平台。

## 为什么需要这个技能？

**创建技能的难点不在于格式——而是知道做事情的最佳方式。**

大多数专业领域都有花费数十年总结出有效方法的大师：
- 乔布斯谈产品、招聘和营销
- 贝索斯谈写作（6页纸文档）和决策
- 芒格谈思维模型
- 克里斯·沃斯谈谈判

这个技能在你写下一行代码之前就呈现他们的方法论，让你的技能从第一天起就具备世界级的专业知识。

## 工作原理

```
1. 你："我想创建一个用户访谈的技能"

2. Skill-from-masters:
   ├── 检查本地方法论数据库
   ├── 搜索网络寻找更多专家
   ├── 寻找优秀产出的范例
   ├── 识别常见错误以避免
   └── 跨来源交叉验证

3. 呈现专家：
   - 罗布·菲茨帕特里克（《妈妈测试》）
   - 史蒂夫·波尔蒂加尔（《访谈用户》）
   - 尼尔森诺曼集团最佳实践

4. 你选择要融入的方法论

5. 从原始来源提取可操作的原则

6. 移交给 skill-creator 生成最终技能
```

## 核心特性

| 特性 | 描述 |
|------|------|
| **三层搜索** | 本地数据库 → 网络搜索专家 → 深入原始来源 |
| **范例收集** | 寻找优秀样本来定义质量标杆 |
| **反模式** | 搜索常见错误以编码"不要这样做" |
| **交叉验证** | 对比多位专家以找到共识并标记分歧 |
| **质量检查清单** | 在生成前验证完整性 |

## 使用方法

当你要求创建新技能时，此技能会自动激活。它在 skill-creator 之前运行，确保你的技能建立在成熟方法论之上。

### 示例会话

**你：** "帮我创建一个写产品需求文档的技能"

**Skill-from-masters：**
> 让我搜索 PRD 写作的最佳方法论。
>
> *[搜索："PRD 最佳实践 专家"、"产品需求文档 方法论"]*
>
> 我找到了几个强大的框架：
>
> **产品管理：**
> - 马蒂·卡根：问题优先的 PRD，将问题空间与解决方案空间分离
> - 特蕾莎·托雷斯：以结果为导向的需求
>
> **商业写作：**
> - 芭芭拉·明托：金字塔原理——先说结论，MECE 结构
> - 亚马逊：逆向工作，6页纸叙事格式
>
> **优秀范例：**
> - Intercom 公开的 PRD 模板
> - Linear 的产品规格格式
>
> **常见错误：**
> - 在定义问题之前就跳到解决方案
> - 为工程师而写而非为对齐而写
> - 缺少成功指标
>
> 哪些方法引起你的共鸣？或者需要我深入搜索任何一个？

**你：** "我喜欢亚马逊的方法结合卡根的问题优先思维。"

**Skill-from-masters：** *[获取亚马逊方法论的主要来源，提取原则，然后通过 skill-creator 生成技能]*

## 技能

本仓库包含以下技能：

| 技能 | 描述 |
|------|------|
| **[skill-from-masters](skill-from-masters/SKILL.md)** | 基于领域专家的成熟方法论创建新技能。 |
| **[search-skill](skills/search-skill/SKILL.md)** | 从可信市场搜索现有技能。 |
| **[skill-from-github](skills/skill-from-github/SKILL.md)** | 向高质量 GitHub 项目学习并基于此知识创建技能。 |

### skill-from-masters

当你想要**基于专家方法论创建新技能**时：

- 三层搜索：本地数据库 → 网络专家 → 原始来源
- 寻找范例和反模式
- 跨多位专家交叉验证
- 移交给 skill-creator 进行最终生成

**示例：**
```
你："帮我创建一个用户访谈的技能"
→ 找到：罗布·菲茨帕特里克（《妈妈测试》）、史蒂夫·波尔蒂加尔、尼尔森诺曼集团
→ 你选择要融入的方法论
→ 生成包含这些原则编码的技能
```

### search-skill

当你想要**寻找现有技能**而非创建时：

- 仅搜索 5 个可信来源（无随机网络结果）
- 基于层级的优先级：官方 → 精选 → 聚合
- 过滤低质量结果（星标 < 10、过时、无 SKILL.md）
- 可疑代码模式安全检查

**示例：**
```
你："我需要一个前端设计、自动化测试和代码审查的技能"
→ 搜索：anthropics/skills、ComposioHQ、travisvn、skills.sh、skillsmp.com
→ 返回：frontend-design（官方）、webapp-testing（官方）、code-review-excellence（26k 星标）
```

### skill-from-github

当你想要**向 GitHub 项目学习**并将知识转化为技能时：

- 搜索优质 GitHub 项目（星标 > 100、积极维护）
- 呈现选项并等待你确认
- 深入研究选定项目（README、源代码、示例）
- 总结所学，然后通过 skill-creator 创建技能

**示例：**
```
你："我想把图片转换成 ASCII 艺术"
→ 搜索 GitHub，找到：ascii-image-converter（3.1k 星标）、RASCII（224 星标）
→ 你选择 ascii-image-converter
→ 学习：亮度到字符映射、宽高比处理、彩色技术
→ 创建编码知识的技能（不只是包装工具）
```

**关键区别：** 此技能编码项目的*知识*，因此即使没有安装原始工具，技能也能工作。

## 质量检查清单

在最终定稿任何技能之前，此技能会验证：

- [ ] 已超越本地数据库进行搜索
- [ ] 找到原始来源，不只是摘要
- [ ] 找到产出的范例
- [ ] 识别要避免的常见错误
- [ ] 跨多位专家交叉验证
- [ ] 编码具体可操作的步骤（非模糊原则）
